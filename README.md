# InternTrack API

A backend REST API for tracking job and internship applications, built with Spring Boot. I'm building it to learn and to use it for my own application pipeline.

## Status

**In progress.** Only the project skeleton exists so far. No features are implemented yet, and this README will grow as each milestone is completed and verified.

## Tech stack (chosen)

- Java 17
- Spring Boot 4.1.2
- Maven
- PostgreSQL, Flyway and Testcontainers (planned, not yet used)
